# A-C17

- Requirement: `C17`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-c17.py`

## Statement

Every new verb has tests for success, precondition failure, and adjective preservation.

## V2 bind

Each verb in `verbs.schema.json` must appear in noun tests, **and** appear in
a test function that uses `assertRaises` / `pytest.raises` / `raises(`.

Does not check adjective preservation. Does not run the tests.

Designed fail: `examples/verb-untested/` (name missing),
`examples/verb-success-only/` (name present, no failure path).
Designed pass: `examples/invoice-correct/`.
