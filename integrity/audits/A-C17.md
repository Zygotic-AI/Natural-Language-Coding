# A-C17

- [Requirement](../../docs/TERMS.md#requirement): `C17`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only
- [Gate](../../docs/TERMS.md#gate): `tools/fitness-c17.py`

## Statement

Every new verb has tests for success, precondition failure, and [adjective](../../docs/TERMS.md#adjective) preservation.

## Bind

Each verb in `verbs.schema.json` must:
- appear in [noun](../../docs/TERMS.md#noun) tests
- appear in a test that uses `assertRaises` / `pytest.raises` / `raises(`
- appear in a *non-raises* test that names an [adjective](../../docs/TERMS.md#adjective) token and asserts

No `adjectives.txt` → preservation skipped. This tool does not execute tests;
CI does.

Designed fail: `examples/verb-untested/`, `examples/verb-success-only/`,
`examples/verb-no-preserve/`.
Designed pass: `examples/invoice-correct/`.
