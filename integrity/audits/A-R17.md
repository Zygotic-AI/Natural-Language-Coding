# A-R17

- Requirement: `R17`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-r17-workflow-citizen.py`

## Statement

Goals may call goals through public contracts. There is no separate workflow citizen. A durable runtime hosts a goal; it does not replace the goal.

## V1 bind

A directory under `workflows/` with both an entrypoint (`implementation.py` /
`run.py` / `main.py`) *and* `input.schema.json` or `output.schema.json` is a
cloned goal.

A thin host file with no goal schemas is allowed. `workflows/` may exist.

Does not prove a Temporal worker is a host.

Designed fail: `examples/workflow-as-goal/`.
Designed pass: `examples/invoice-correct/` (no workflows/).
