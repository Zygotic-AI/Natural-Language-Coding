# A-R18

- Requirement: `R18`
- Outcome: **met** | **not met** only

## Statement

Compensation and retries live in the calling goal (and its runtime if durable), not inside the noun, unless the noun's adjective itself requires idempotency of a verb. Verbs must be safe to retry if a durable goal retries them. Declare that on the verb.

## Binary criteria

Met iff a gate (CI check, confirmer step, or fitness tool) has verified this requirement against the current change and recorded PASS with evidence. Not met if no gate ran, the gate failed, or evidence is missing.

## Evidence

On met or not met, cite file and symbol (or N/A reason). List failing ids when the audit is a matrix audit.

## Gate

Unbound. No fail-capable gate registered.
