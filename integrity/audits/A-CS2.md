# A-CS2

- Requirement: `CS2`
- Outcome: **met** | **not met** only

## Statement

Each verb has input, output, and failure mode.

## Binary criteria

Met iff every verb in the changed agent noun's `verbs.md` has all three: input contract, output contract, failure mode. Not met if any verb is missing any element.

## Evidence

On met or not met, cite `agents/<name>/verbs.md` and the verb name with missing element.
