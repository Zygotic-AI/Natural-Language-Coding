# A-CS2

- [Requirement](../../docs/TERMS.md#requirement): `CS2`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only

## Statement

Each verb has input, output, and failure mode.

## Binary criteria

[Met](../../docs/TERMS.md#met) iff every verb in the changed [agent noun](../../docs/TERMS.md#agent-noun)'s `verbs.md` has all three: input [contract](../../docs/TERMS.md#contract), output [contract](../../docs/TERMS.md#contract), failure mode. Not [met](../../docs/TERMS.md#met) if any verb is missing any element.

## Evidence

On [met](../../docs/TERMS.md#met) or not [met](../../docs/TERMS.md#met), cite `agents/<name>/verbs.md` and the verb name with missing element.
