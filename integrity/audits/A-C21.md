# A-C21

- Requirement: `C21`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-c21.py`

## Statement

Impact list in the proposal matches generated callers of the changed verbs/goals.

## V1 bind

If `PROPOSAL.md` or `CONFIRM.md` exists at the scan root, every caller from
`generate-impact-graph.py` must appear in that note (case-insensitive).

No note file → skip (MET). That is not proof the change had no impact.

Designed fail: `examples/impact-list-mismatch/`.
Designed pass: `examples/invoice-correct/`.
