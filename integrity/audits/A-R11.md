# A-R11

- [Requirement](../../docs/TERMS.md#requirement): `R11`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only
- [Gate](../../docs/TERMS.md#gate): `tools/fitness-schema-identity.py`

## Statement

A field that means the same thing in two contracts is defined once and referenced. Duplicate independent definitions of the same meaning are a [defect](../../docs/TERMS.md#defect).

## V1 bind

Same *name* with two JSON `type`s in one tree fails.

Does **not** detect two names that mean the same thing (`balance` vs `remaining`).

Designed fail: `examples/schema-identity-violation/` (`amount` integer vs string).
Designed pass: `examples/invoice-correct/`.
