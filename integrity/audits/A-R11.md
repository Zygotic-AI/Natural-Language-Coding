# A-R11

- Requirement: `R11`
- Outcome: **met** | **not met** only

## Statement

A field that means the same thing in two contracts is defined once and referenced. Duplicate independent definitions of the same meaning are a defect.

## V1 tool (not a matrix bind)

`tools/fitness-schema-identity.py` — same *name* with two JSON `type`s in one tree fails.

Designed fail: `examples/schema-identity-violation/` (`amount` integer vs string).
Designed pass: `examples/invoice-correct/`.

V1 does not detect two names that mean the same thing (`balance` vs `remaining`). R11 stays unbound.
