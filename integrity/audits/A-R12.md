# A-R12

- [Requirement](../../docs/TERMS.md#requirement): `R12`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only
- [Gate](../../docs/TERMS.md#gate): `tools/fitness-r12-version.py`

## Statement

Contracts are versioned. Breaking changes require a new version and an [ADR](../../docs/TERMS.md#adr).

## V1 bind

Public [contract](../../docs/TERMS.md#contract) JSON (`input.schema.json`, `output.schema.json`, `failure.schema.json`,
`schemas/verbs.schema.json`) must have a top-level `version` (non-empty string or number).

Does **not** detect a breaking change or require an [ADR](../../docs/TERMS.md#adr). That is C10, still unbound.

Designed fail: `examples/unversioned-contract/`.
Designed pass: `examples/invoice-correct/`.
