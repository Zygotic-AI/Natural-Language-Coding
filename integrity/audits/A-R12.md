# A-R12

- Requirement: `R12`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-r12-version.py`

## Statement

Contracts are versioned. Breaking changes require a new version and an ADR.

## V1 bind

Public contract JSON (`input.schema.json`, `output.schema.json`, `failure.schema.json`,
`schemas/verbs.schema.json`) must have a top-level `version` (non-empty string or number).

Does **not** detect a breaking change or require an ADR. That is C10, still unbound.

Designed fail: `examples/unversioned-contract/`.
Designed pass: `examples/invoice-correct/`.
