# A-C15

- Requirement: `C15`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-c15-idempotent.py`

## Statement

Verbs invoked from a retrying (durable) goal are idempotent, or the caller uses an idempotency key the verb honors.

## V1 bind

If a goal `.py` contains retry/temporalio/durable/`for attempt in`, each
`obj.verb(` call must have `"idempotent": true` in `verbs.schema.json`.

No retry marker → skip (MET). Does not honor an idempotency *key* argument.

Designed fail: `examples/retrying-goal/`.
Designed pass: `examples/invoice-correct/`.
