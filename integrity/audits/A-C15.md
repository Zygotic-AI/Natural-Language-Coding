# A-C15

- Requirement: `C15`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-c15-idempotent.py`

## Statement

Verbs invoked from a retrying (durable) goal are idempotent, or the caller uses an idempotency key the verb honors.

## V2 bind

Retrying goal (retry/temporalio/durable/`for attempt in`):
- verb must have `"idempotent": true`
- schema must declare `idempotency_key` or `idempotent_key`
- call site must pass that key by name

No retry marker → skip (MET). Nested parens in the call are not parsed.

Designed fail: `examples/retrying-goal/` (flag missing),
`examples/retrying-no-key/` (flag present, key not passed).
Designed pass: `examples/invoice-correct/`.
