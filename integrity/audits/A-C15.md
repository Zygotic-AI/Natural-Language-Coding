# A-C15

- Requirement: `C15`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-c15-idempotent.py`

## Statement

Verbs invoked from a retrying (durable) goal are idempotent, or the caller uses an idempotency key the verb honors.

## Bind

Retrying goal (retry/temporalio/durable/`for attempt in`):
- verb `"idempotent": true`
- schema declares `idempotency_key` / `idempotent_key`
- call site passes that key by name (nested parens parsed)
- the verb *body* uses the key (not only a parameter)

No retry marker → skip.

Designed fail: `examples/retrying-goal/`, `examples/retrying-no-key/`,
`examples/retrying-nested-no-key/`, `examples/retrying-key-unused/`.
Designed pass: `examples/invoice-correct/` (no retry),
`examples/retrying-nested-ok/`.
