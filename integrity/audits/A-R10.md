# A-R10

- Requirement: `R10`
- Outcome: **met** | **not met** only

## Statement

Every public noun-verb has an input contract and an output contract.

## V1 tool (not a matrix bind)

Same tool as A-R9. Nouns need `domain/<noun>/schemas/verbs.schema.json` with at
least one verb declaring `input` and `output`.

R10 stays unbound. File shape ≠ verb-by-verb completeness.
