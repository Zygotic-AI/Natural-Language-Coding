# A-S1

- [Requirement](../../docs/TERMS.md#requirement): `S1`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only

## Statement

Every [agent noun](../../docs/TERMS.md#agent-noun) has an identity file that states purpose and adjectives.

## Binary criteria

[Met](../../docs/TERMS.md#met) iff every [agent noun](../../docs/TERMS.md#agent-noun) package under `agents/<name>/` contains an `AGENT.md` (or equivalent) that states:
1. Role name
2. Purpose (one line)
3. Adjectives (list)

Not [met](../../docs/TERMS.md#met) if any [agent noun](../../docs/TERMS.md#agent-noun) package is missing identity or adjectives, or if they are vague/missing binary criteria.

## Evidence

On [met](../../docs/TERMS.md#met) or not [met](../../docs/TERMS.md#met), cite `agents/<name>/AGENT.md` and the relevant sections. List each [agent noun](../../docs/TERMS.md#agent-noun) checked.
