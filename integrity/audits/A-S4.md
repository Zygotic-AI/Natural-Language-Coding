# A-S4

- [Requirement](../../docs/TERMS.md#requirement): `S4`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only

## Statement

Success criteria are binary: ops (work completed as specified) vs defects (deviation from spec or adjectives).

## Binary criteria

[Met](../../docs/TERMS.md#met) iff every [agent noun](../../docs/TERMS.md#agent-noun) package contains a success criteria table with:
1. Ops column (what success looks like)
2. [Defect](../../docs/TERMS.md#defect) column (what failure looks like)
3. Each row is binary (not "mostly" or "usually")

Not [met](../../docs/TERMS.md#met) if success criteria are missing, vague, or not binary.

## Evidence

On [met](../../docs/TERMS.md#met) or not [met](../../docs/TERMS.md#met), cite `agents/<name>/AGENT.md` success criteria section. List each [agent noun](../../docs/TERMS.md#agent-noun) checked.
