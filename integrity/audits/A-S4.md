# A-S4

- Requirement: `S4`
- Outcome: **met** | **not met** only

## Statement

Success criteria are binary: ops (work completed as specified) vs defects (deviation from spec or invariants).

## Binary criteria

Met iff every agent noun package contains a success criteria table with:
1. Ops column (what success looks like)
2. Defect column (what failure looks like)
3. Each row is binary (not "mostly" or "usually")

Not met if success criteria are missing, vague, or not binary.

## Evidence

On met or not met, cite `agents/<name>/AGENT.md` success criteria section. List each agent noun checked.
