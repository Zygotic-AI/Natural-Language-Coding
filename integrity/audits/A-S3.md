# A-S3

- Requirement: `S3`
- Outcome: **met** | **not met** only

## Statement

Every agent noun declares handoff-in (preconditions) and completion artifact (postconditions).

## Binary criteria

Met iff every agent noun package contains:
1. Handoff-in section with preconditions table or list
2. Completion artifact section with what the agent produces

Not met if any agent noun is missing either element.

## Evidence

On met or not met, cite `agents/<name>/AGENT.md` handoff-in and completion artifact sections. List each agent noun checked.
