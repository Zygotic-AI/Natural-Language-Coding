# A-R20

- Requirement: `R20`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-r20.py`

## Statement

The charter, contracts, and code must agree.

## V2 bind

Each `input.required` field on a verb in `verbs.schema.json` must appear in
that method's signature or body. If the signature annotates the field and
the schema gives a JSON type, they must match (integer↔int, string↔str,
boolean↔bool, number↔int|float).

Does not prove charter text matches code (that is still R27 / the matrix).
Unannotated params skip the type check.

Designed fail: `examples/schema-field-missing/`, `examples/schema-type-mismatch/`.
Designed pass: `examples/invoice-correct/`.
