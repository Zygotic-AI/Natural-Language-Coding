# A-R23

- [Requirement](../../docs/TERMS.md#requirement): `R23`
- Outcome: **[met](../../docs/TERMS.md#met)** | **not [met](../../docs/TERMS.md#met)** only
- [Gate](../../docs/TERMS.md#gate): `tools/fitness-no-noun-field-writes.py`

## Statement

A [gate](../../docs/TERMS.md#gate) fails the change if a [goal](../../docs/TERMS.md#goal) or adapter assigns a [noun](../../docs/TERMS.md#noun) field or imports a [noun](../../docs/TERMS.md#noun) internals module.

## Binary criteria

[Met](../../docs/TERMS.md#met) iff the registered [gate](../../docs/TERMS.md#gate) exits 0 with `RESULT:MET` on the scanned tree. Not [met](../../docs/TERMS.md#met) if the [gate](../../docs/TERMS.md#gate) prints `VIOLATION` / exits 1, did not run, or evidence is missing.

Field-assignment half is covered by `fitness-no-noun-field-writes.py`. Import-of-internals half is a sibling concern of R6/C5 and `fitness-noun-imports.py` where that tool exists.

## Evidence

Cite each `VIOLATION` line, or `RESULT:MET` with the scan roots used.
