# A-C18

- Requirement: `C18`
- Outcome: **met** | **not met** only
- Gate: `tools/fitness-c18.py`

## Statement

Goal tests cover the use-case, not a copy of the noun's adjective suite.

## Bind

A goal with implementation `.py` must have tests that **call** a public
function from that impl (`name(`). Those tests must not mention tokens from
`domain/<noun>/adjectives.txt`.

This tool does not execute tests; CI does.

Designed fail: `examples/goal-untested/`, `examples/goal-tests-copy-adjectives/`,
`examples/goal-test-no-call/`.
Designed pass: `examples/invoice-correct/`.
