# ADR 0053 — Text retrofit for Accepted ADRs 0051 and 0052

- Status: Proposed
- Date: 2026-10-13
- Deciders: Human manager
- Class: F (integrity / hub produce)
- Corpus: nlc
- Amends: [ADR 0051](0051-hub-own-produce-principles.md), [ADR 0052](0052-owner-openpgp-ratification-amends-0051.md) text only (those files stay untouched so their sidecars and hashes stay valid)

## Context

ADRs 0051 and 0052 are Accepted. Editing their bytes would invalidate signatures and stamps. Several sentences in those files are stale now that the codified constraints are wired (this produce package, C1–C11).

## Decision

When this record is Accepted, the following text replacements apply to 0051/0052. Until then they are the intended wording only.

1. **Gate-set path table (0051).** The category table under “Gate set (paths)” is historical. Membership is derived by `tools/nouns/gate_set/gate_set.py` (`derive_gate_set_paths`) from CI workflow seeds. The table is not a hand-kept allowlist.

2. **`integrity/gate-change-receipts.json` (0051 SG2).** That filename is stale. The in-force registry is the signed gate-set manifest `integrity/gate-set-baseline.manifest.sha256` plus its OpenPGP sidecar.

3. **“This Proposed record does not wire CI” (0051 Decision 5).** That deferral is spent. The hub profile, sidecar, known-bad SSOT, and related checks are wired in `ci_fitness`.

4. **Step-1 notes (0052 Consequences).** “No fitness or receipt changes until owner signs and step 2 lands” is spent. Step 2 is this wiring. Hash-only `integrity/adr-approval-receipts.json` is a completion confirmation only and is not ratification.

## Consequences

- 0051 and 0052 file bytes stay unchanged until the owner re-signs replacement text or accepts this ADR and a follow-on edit.
- Version class **patch** for this Proposed record alone; the C1–C11 wiring that this record describes is **minor**.

## Rejected

- Editing 0051 or 0052 in the same change that wires CI (would invalidate their stamps).
- Treating the stale table or `gate-change-receipts.json` name as still in force.
