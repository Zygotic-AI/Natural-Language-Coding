# ADR 0034 — Charter goal shape and composition (R13–R19)

- Status: Accepted
- Date: 2026-09-23
- Deciders: Human manager
- Class: A (charter shape)
- Corpus: bba
- Ratifies: R13, R14, R15, R16, R17, R18, R19

## Context

Goal shape and composition rules had binders without a dedicated ADR decision trail.

## Decision

Adopt charter §5.4–§5.5:

- **R13–R16:** One public entrypoint; call goals only via public contracts; noun-protected logic stays on the noun; goals are use-cases not functions.
- **R17–R19:** No separate workflow citizen; compensation/retries in the calling goal; no hand-authored duplicate execution graphs.

## Consequences

- Backlog marks R13–R19 ratified by this ADR.
- Binders unchanged.

## Rejected

- Workflow as a peer citizen above goals.
