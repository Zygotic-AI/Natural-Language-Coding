# ADR 0002 — Scope of P2 (zero variance)

- Status: Accepted
- Date: 2026-09-04
- Deciders: Richard Pickett
- Class: F (charter clarification)

## Context

P2 currently reads as “every action that changes an adopting BBP system is prescribed.” That is correct for this hub’s requirement loop and for class A/B (and D/E/F) gates. Applied to all coding motion it becomes governance under a new name. Agents need prescribed boundaries, not a script for every keystroke.

ADR 0001 decision 2 and `integrity/PRINCIPLES.md` P2 can be over-read as: every edit is a gated procedure.

## Decision

P2 binds:

- (a) changes to the practice hub’s in-force surfaces and integrity machinery, and
- (b) the prescribed agent-loop **gates** for change classes A, B, D, E, F.

P2 does not require a prescribed action for every edit inside an already-ratified noun-verb or goal implementation.

Unprescribed **boundary crossings** remain incomplete work.

## Consequences

- Update P2 audit language so “unprescribed action” means “skipped a required gate or crossed a noun boundary without a verb,” not “wrote code without a ticket.”
- Charter §5.8 cites this ADR for P2 scope. Rule numbers are unchanged.
- P2 remains unbound in the binding matrix until a fail-capable binder exists.

## Rejected

- “Every keystroke is a gated procedure.”
