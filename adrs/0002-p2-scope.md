# [ADR](../docs/TERMS.md#adr) 0002 — Scope of P2 (zero variance)

- Status: Accepted
- Date: 2026-09-04
- Deciders: Richard Pickett
- Class: F (charter clarification)

## Context

P2 currently reads as “every [action](../docs/TERMS.md#action) that changes an adopting [BBP](../docs/TERMS.md#bbp) system is prescribed.” That is correct for this [hub](../docs/TERMS.md#hub)’s [requirement](../docs/TERMS.md#requirement) loop and for class A/B (and D/E/F) gates. Applied to all coding motion it becomes governance under a new name. Agents need prescribed boundaries, not a script for every keystroke.

[ADR](../docs/TERMS.md#adr) 0001 decision 2 and `integrity/PRINCIPLES.md` P2 can be over-read as: every edit is a gated procedure.

## Decision

P2 binds:

- (a) changes to the practice [hub](../docs/TERMS.md#hub)’s in-force surfaces and [integrity](../docs/TERMS.md#integrity) machinery, and
- (b) the prescribed agent-loop **gates** for change classes A, B, D, E, F.

P2 does not require a prescribed [action](../docs/TERMS.md#action) for every edit inside an already-ratified noun-verb or [goal](../docs/TERMS.md#goal) implementation.

Unprescribed **[boundary](../docs/TERMS.md#boundary) crossings** remain incomplete work.

## Consequences

- Update P2 [audit](../docs/TERMS.md#audit) language so “unprescribed [action](../docs/TERMS.md#action)” means “skipped a required [gate](../docs/TERMS.md#gate) or crossed a [noun](../docs/TERMS.md#noun) [boundary](../docs/TERMS.md#boundary) without a verb,” not “wrote code without a ticket.”
- [Charter](../docs/TERMS.md#charter) §5.8 cites this [ADR](../docs/TERMS.md#adr) for P2 scope. [Rule](../docs/TERMS.md#rule) numbers are unchanged.
- P2 remains unbound in the [binding matrix](../docs/TERMS.md#binding-matrix) until a fail-capable binder exists.

## Rejected

- “Every keystroke is a gated procedure.”
