# [BBP](../../../docs/TERMS.md#bbp) Recorder

[Gate](../../../docs/TERMS.md#gate): `G-RECORD`. [Charter](../../../docs/TERMS.md#charter) §6 Step 8, R22.

SSOT role: [`agents/recorder.md`](../../../agents/recorder.md).

**Complete:** an [ADR](../../../docs/TERMS.md#adr) added or updated, **or** a written “no [ADR](../../../docs/TERMS.md#adr), reason” note. Deciders are role names (CG-R4). Do not change binding-matrix statuses unless a later prompt says so.

**Incomplete:** decision trail missing, or matrix rows flipped without authorization.

Breaking published contracts: [ADR 0006](../../../adrs/0006-contract-change-notice.md) — loudness is a red [prove](../../../docs/TERMS.md#prove), not a chat ping.
