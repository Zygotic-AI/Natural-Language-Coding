# Natural Language Coding hub v0.2.0

Hub **v0.2.0** closes the **v1 compiled-system product** surface: machine-backed use-case rows, semantic rule IR runner/apply, hub X4 noun tooling, verify/CI hardening, and a **resumable `./release`** ship path. Expansion work (composable IR v2, full multi-language scanners, public pack registry) stays documented as residuals, not blockers for this tag.

## Highlights

- **Compiled-system product (UC1–UC21 v1)** — Product rows in `integrity/uc-product-status.json` align with landmine examples, assert/fitness gates, interview/requirements sync, ADR traceability, rule coverage, goal bindings, delta regen, verify provenance, durable-engine rules, adapter boundaries, and adopter verify specimens.
- **ADR 0007 semantics (UC4 / UC5 v2)** — Hub semantic rule runner (`check_semantic_ir`) and semantic apply (`check_semantic_apply`, `nlc:obligation=` receipts) with v2 specimens; structural-only runner/apply paths remain for negative tests.
- **Hub X4 tooling** — Emit-path and fitness/assert noun packages; `fitness_only` / `assert_only` tranches closed; release-signed simulation passes on clean `main`.
- **Verify and produce** — Stronger `verify` / `verify-deep`, produce-package preflight, SSOT exit evidence, expanded `ci_fitness`, and handoff gates so regressions fail in CI before tag.
- **SSOT and honesty** — FINDINGS ↔ TODO ↔ use-case matrix fitness; jobs/todo sync; product-completion inference record (P8); integration-leaves hygiene; RCAs where “done” was overstated.
- **Hub v0.2 packs (v1 scope)** — Pack ingest and **consume/regen after install** closed for hub dogfood; curated **hub pack registry** (not a public internet registry).
- **Release mechanics (ADR 0022 / 0039)** — `./release` resumable orchestrator, release-prep profile, resume probe (`git_tag_on_merge`, stale `release/v*`), tag gate, and agent **`/release`** closeout (continuity commit + inference, not operator checklists).
- **Agent harness** — Portable skills and instructions: planit, verify, interview, bbp-*, **`take-me-literally`** (verbatim user scope), **plain-language reply references**, release skill SSOT under `.agents/`.
- **Distribution** — Install scripts, install hashes, `nlc` CLI surfaces, and adoption docs updated for the expanded hub.

**Explicitly not in v0.2.0**

- UC14 **composable rule IR v2** (cross-primitive obligations beyond current hub snapshot).
- UC16 / UC20 **full expansion** (reference TypeScript adapter and call-tree pack only; broader language/scanner waves parked).
- **Public internet pack registry** and optional out-of-band registry product rows.
