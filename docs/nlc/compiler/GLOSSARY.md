# Words we use

Short index—**full dictionary:** [`TERMS.md`](../../TERMS.md). Full intent split: [INTENT-SURFACE.md](INTENT-SURFACE.md).

| Term | Meaning |
| ---- | ------- |
| **[NLC](../../TERMS.md#nlc)** | [Natural Language Coding](../../TERMS.md#nlc) — the product. |
| **[Compiler](../../TERMS.md#compiler)** | [AI system compiler](../../TERMS.md#compiler) — turns bound intent into a [compiled system](../../TERMS.md#compiled-system). Optional acronym **[ASC](../../TERMS.md#asc)** (avoid in first-read copy). |
| **[Compiled system](../../TERMS.md#compiled-system)** | Runnable BBP-shaped code in your [app repo](../../TERMS.md#adopter). Optional acronym **[ACS](../../TERMS.md#acs)** (artifact only). |
| **[Goal](../../TERMS.md#goal)** | Outcome the system must deliver. |
| **[Requirement](../../TERMS.md#requirement)** | Constraint, standard, or policy in prose until adopted as ADR/rules. |
| **[Knowledge domain](../../TERMS.md#knowledge-domain)** | Standing facts, ADRs, and requirements the [interview](../../TERMS.md#interview) must consult. |
| **[ADR](../../TERMS.md#adr)** | Dated decision (why); may reduce to executable rules. |
| **[Rule](../../TERMS.md#rule)** | If/then over tags, primitives, and facts — what the [compiler](../../TERMS.md#compiler) runs after adoption. |
| **[BBP](../../TERMS.md#bbp)** | [Boundary-Based Programming](../../TERMS.md#bbp) — emit shape. |
| **[BBA](../../TERMS.md#bba)** | [Boundary-Based Architecture](../../TERMS.md#bba) — [hub](../../TERMS.md#hub) [charter](../../TERMS.md#charter) and [integrity](../../TERMS.md#integrity) (under the covers). |
| **[PLANIT](../../TERMS.md#planit)** | Load → [interview](../../TERMS.md#interview) → plan → bind → generate → [gate](../../TERMS.md#gate) → [prove](../../TERMS.md#prove). Slash: `/planit`. |
| **[Prove](../../TERMS.md#prove)** | Machine fitness + adversarial [audit](../../TERMS.md#audit) — **compile** green. Not [ship](../../TERMS.md#ship). |
| **[Ship](../../TERMS.md#ship)** | Human `Released-by:` (and `Ratified-by:` when required) after [prove](../../TERMS.md#prove). |

[Quality](../../TERMS.md#quality) method names (DMAIC, DFSS, …): [QUALITY-PROCESSES.md](QUALITY-PROCESSES.md).
