# Words we use

Short glossary for Natural Language Coding. Full intent split: [INTENT-SURFACE.md](INTENT-SURFACE.md).

| Term | Meaning |
| ---- | ------- |
| **NLC** | Natural Language Coding — the product. |
| **Compiler** | AI system compiler — turns bound intent into a compiled system. Optional acronym **ASC** (avoid in first-read copy). |
| **Compiled system** | Runnable BBP-shaped code in your app repo. Optional acronym **ACS** (artifact only). |
| **Goal** | Outcome the system must deliver. |
| **Requirement** | Constraint, standard, or policy in prose until adopted as ADR/rules. |
| **Knowledge domain** | Standing facts, ADRs, and requirements the interview must consult. |
| **ADR** | Dated decision (why); may reduce to executable rules. |
| **Rule** | If/then over tags, primitives, and facts — what the compiler runs after adoption. |
| **BBP** | Boundary-Based Programming — emit shape. |
| **BBA** | Boundary-Based Architecture — hub charter and integrity (under the covers). |
| **PLANIT** | Load → interview → plan → bind → generate → gate → prove. Slash: `/planit`. |
| **Prove** | Machine fitness + adversarial audit — **compile** green. Not ship. |
| **Ship** | Human `Released-by:` (and `Ratified-by:` when required) after prove. |

Quality method names (DMAIC, DFSS, …): [QUALITY-PROCESSES.md](QUALITY-PROCESSES.md).
