## R1 — ADRs 0046–0049 + receipts

### What a reviewer must check

- Each ADR **Decision** matches wired gates (grep `integrity/adr-gates.json` and `fitness-adr-approval.py` paths).
- `integrity/adr-approval-receipts.json` hashes match **current** ADR bytes for 0046–0049 (and bulk block for 0001–0043 if touched).
- No active ADR row in `docs/ADR-ENFORCEMENT.md` still marked **gap** for 0046–0049.
- Ratification headers (`Ratified-by`, deciders) use **role language** per contribution gate CG-R4 where re-ratification is required (see open PR #9 for 0001–0003 / 0050).

### Defects / unbacked claims to watch

- **0046:** Cursor hook + `fitness-planit-identity.py` must both fail on skill drift; `.nlc/planit-change-evidence.json` must update on tree changes (landmines exist — confirm MET on `release/v0.3.0`).
- **0047:** Bulk receipt object for 0001–0043 — any ADR edit without receipt refresh must fail; confirm fixtures exist for 0007, 0009, 0028 violations.
- **0048:** `unclassified` count must be zero before gate is “on”; release policy under `goals/hub_release/` not re-expanded in `scripts/nlc-release.sh`.
- **0049:** Every `./release` stop must map to planner observation facts — spot-check for stray `exit 1` messages in executor without planner action kind.

### Disposition guidance

| ADR | Recommendation |
| --- | ---------------- |
| 0046 | **Stay** — aligns hub Planit with one skill identity. |
| 0047 | **Stay** — necessary for honest “Accepted” bytes; pair with owner re-ratification PRs when headers change. |
| 0048 | **Stay** — clarifies non-runtime; verify inventory when new top-level scripts land. |
| 0049 | **Stay** — closes stop fragmentation; review RCA link out-of-repo policy consistently with 0050. |

### Plain-language summary (owner ratification)

- **0046 — Repository Planit identity:** The hub’s `/planit` skill is one specific file with a recorded hash; if Cursor or another harness loads a different planit skill or an edited copy, intake and hooks must fail until the registry and evidence are updated.
- **0047 — ADR approval receipts:** “Accepted” on an ADR is not enough; the hub stores a cryptographic hash receipt per active ADR and refuses compile if the file changes without a new human ratification record.
- **0048 — Executable shape:** The repo classifies every script as a thin entrypoint, goal, noun, adapter, or fixture; policy-heavy release logic belongs under `goals/`, not fat shell wrappers, and unclassified files fail CI.
- **0049 — Release planner owns stops:** `./release` may only pause or stop for reasons the release-state planner already models; the shell executor must not invent new stop types or remediation branches outside that planner.
